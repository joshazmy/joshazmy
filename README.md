# Joshua Azmy

Self-taught developer in Orlando, Florida. I ship small tools and finish them:
Chrome extensions, local-first AI utilities, Linux desktop apps.

Currently building **Tavuno** — an AI phone receptionist for small businesses — and
finishing Harvard's CS50P.

### Shipped

- **[StockyLift](https://github.com/joshazmy/stockylift)** — Chrome Web Store extension
  that exports Shopify Stocky suppliers as CSV/JSON. ~$500 from ~30 paying customers
  before Shopify shut Stocky down in Aug 2026.
- **[Freeflow](https://github.com/joshazmy/freeflow)** — 100% local Linux dictation.
  whisper.cpp on-device, a local LLM cleans up the text, it lands at your cursor.
  No cloud, no accounts, no telemetry.
- **[effectcraft-ai-chat](https://github.com/joshazmy/effectcraft-ai-chat)** — AI chat
  panel for After Effects: local models, Codex, Devin ACP, OpenCode, any CLI.
- **[claude-usage-gauge](https://github.com/joshazmy/claude-usage-gauge)** — ESP32-S3
  desk gadget showing live Claude usage as pixel art.
- **[Yapel](https://github.com/joshazmy/cider-ytm)** — Linux desktop player for YouTube
  Music, GPL fork of Limusic, with end-to-end tests.
